## 🚀 Featured Project

<table align="center">
<tr>
<td width="100%">

### 🎙️ VoiceSQL AI — Voice-to-SQL Query Generator

An AI-powered application that allows users to interact with databases using **natural language and voice**.

Instead of manually writing SQL queries, users can ask questions such as:

> "Show me the top 5 students with the highest marks."

VoiceSQL AI converts the natural-language request into a PostgreSQL query and executes it against the connected database.

### ✨ Key Features

- 🎤 Voice-to-text query input
- 🧠 AI-powered SQL generation
- 🗄️ PostgreSQL database integration
- 🔐 User authentication
- 🌐 Google OAuth authentication
- 📊 Query history
- 📈 Analytics dashboard
- ⚡ Query execution
- 🛡️ Read-only SQL safety validation
- ❌ Failed-query tracking
- 📋 Generated SQL and result display
- 🗂️ Database schema awareness

### 🧰 Technologies

`React` `JavaScript` `Flask` `Python` `PostgreSQL` `Gemini API` `Web Speech API` `JWT` `Google OAuth`
